<h1 align="center">🔥 Blueprint Hell (Java)</h1>

<p align="center">
  یک پروژه درس برنامه‌نویسی پیشرفته که یک بازی <i>Event-Driven</i> را شبیه‌سازی می‌کند.  
  در این پروژه سیستم‌های مختلف به هم متصل شده و پیام‌ها بین آن‌ها منتقل می‌شوند.  
  پروژه با اصول <b>Clean Code</b> و <b>OOP</b> نوشته شده و از <b>Design Patterns</b> کلیدی استفاده شده است.  
  بازی دارای مکانیزم ذخیره‌سازی، ارتقا و قابلیت تبدیل به نسخه مولتی‌پلیر است.
</p>

## ✨ ویژگی‌ها
- مدیریت پروژه با **Maven**  
- طراحی شی‌گرای قوی (**OOP**) با اشیا ریز و درشت  
- استفاده از **Design Patterns**: Observer, Factory, Builder  
- معماری **Event-Driven** برای تعامل بین سیستم‌ها  
- ذخیره‌سازی و بازیابی اطلاعات بازی (**Data Persistence**)  
- طراحی مراحل پویا و قابل توسعه (**Extensible Stage Design**)  
- ساختار ماژولار و قابل ارتقا (**Modular & Extensible**)  
- طراحی شده برای امکان **مولتی‌پلیر و اجرای چندنخی**
