<p align="center">

  پروژه با اصول <b>Clean Code</b> و <b>OOP</b> نوشته شده و از <b>Design Patterns</b> کلیدی استفاده شده است.  
  بازی دارای مکانیزم ذخیره‌سازی، ارتقا و قابلیت تبدیل به نسخه مولتی‌پلیر است.
